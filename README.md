# دليل سوريا | DALIL SYRIA
### الدليل الوطني الرقمي الموحد للمعاملات والجهات والخرائط والنقل في الجمهورية العربية السورية
**National Digital Directory of Public Services, Transactions, GIS Locations & Transport in the Syrian Arab Republic**

---

## 🇸🇾 نظرة عامة على المشروع (Project Overview)

**دليل سوريا | DALIL SYRIA** هو تطبيق إنتاجي متكامل، يعمل كمرجع وطني موحد للمواطنين والمقيمين والمغتربين السوريين. يغطي المعاملات الرسمية، الخرائط الجغرافية (GIS)، وأجور النقل البري بين المحافظات، دون الاعتماد على أي معلومات تخمينية أو بيانات غير موثقة.

### 🌟 المبدأ الأساسي: لا معلومات مختلقة (Zero Hallucination Policy)
- **دقة مطلقة**: لا يتم اختلاق أو تخمين أي رسم مالي، جهة حكومية، ساعات دوام، أو إحداثيات جغرافية.
- **التوثيق بالمرسوم والقانون**: كل معاملة ورسم مالي مرتبط برقم القانون أو المرسوم التشريعي النافذ (مثل القانون رقم 37 لعام 2023 للأحوال المدنية، قرارات وزارة الداخلية لعام 2024 لرسوم الجوازات، وقانون البيوع العقارية رقم 15 لعام 2021).
- **التصنيف الواضح**: تمييز دقيق بين «موثق ورسمي»، «منشور من جهة موثوقة»، و«بانتظار التحقق».
- **عدم التخمين**: في حال عدم ثبوت معلومة، يتم التصريح بـ «غير متوفر حالياً» أو «بانتظار التحقق» بدلاً من تخمينها.

## 🗺️ نظام الخرائط الجغرافية GIS والملاحة

- خريطة تفاعلية كاملة لسورية مبنية عبر **Leaflet** ومزودة بطبقات خرائط عالية الأداء (CartoDB Dark Matter / Positron) المتوافقة مع النمط الليلي والنهاري.
- تحديد مواقع فروع الهجرة والجوازات، قصور العدل، المصالح العقارية، ومراكز البولمان بإحداثيات GPS حقيقية غير افتراضية.
- **تحديد الموقع بدقة (GPS)** بموافقة صريحة من المستخدم مع استعراض نسبة الدقة.
- **دبوس تفاعلي قابل للسحب (Draggable User Pin)** لاختيار أي موقع مخصص في سورية وحساب المسافات آلياً.
- **حساب المسافات الكروية (Haversine Formula)**:
  $$d = 2R \cdot \arcsin\left(\sqrt{\sin^2\left(\frac{\Delta\phi}{2}\right) + \cos(\phi_1)\cos(\phi_2)\sin^2\left(\frac{\Delta\lambda}{2}\right)}\right)$$
  حيث $R = 6371\text{ km}$، مع ترتيب المراكز والجهات تصاعدياً من الأقرب إلى الأبعد.
- زر **«الاتجاهات والملاحة»** الذي يفتح تطبيق الخرائط الأصلي (Google Maps / Apple Maps / OSM) بإحداثيات الوجهة المحددة بدقة.

## 🔍 محرك البحث الذكي المحلي (Local NLP Search Engine)

- يفهم الأسئلة الطبيعية باللغة العربية، مثل:
  > *«أريد استخراج جواز سفر في طرطوس، ما الأوراق والرسوم وأين أذهب؟»*
- استخراج الكيانات (المعاملة، المحافظة، النوايا: رسوم، أوراق، مواقع).
- تطبيع الحروف العربية (أ، إ، آ -> ا / ة -> ه / ى -> ي / إزالة التشكيل والتنوين).
- يعمل **100% محلياً ودون إنترنت (Offline-First)** دون اشتراط أي مفتاح أو نموذج لغوي مدفوع.
- طبقة تكامل خادمي اختيارية (Server Proxy) مع Gemini API عبر `/api/ai/assistant` مع منع صارم للاختلاق.

## 📱 متطلبات تثبيت PWA ونظام Android

- تطبيق ويب تقدمي متكامل (PWA) عبر `vite-plugin-pwa` مع سجل تحديث تلقائي.
- دعم كامل لملف `manifest.json`، وأيقونات تكيفية (Maskable Icons 192x192 و 512x512) و `apple-touch-icon.png`.
- زر تثبيت ذكي `PWAInstallButton` يخفي نفسه تلقائياً عند التشغيل في النمط المستقل (Standalone Mode)، ويوفر دليلاً تفاعلياً لمستخدمي iOS Safari.
- دعم مشاركة الروابط عبر `navigator.share` (Web Share API) مع التراجع الذكي لنسخ الرابط في الحافظة.

## 🚀 التشغيل المحلي والبناء (Local Development & Build)

### المتطلبات (Prerequisites)
- Node.js v18+ أو v20+ أو v22+
- npm أو bun

### خطوات التشغيل (Quick Start)
```bash
# 1. تثبيت الاعتماديات
npm install

# 2. تشغيل خادم التطوير (Full-Stack Dev Server)
npm run dev
# سيعمل التطبيق على الرابط: http://localhost:3000

# 3. التحقق من سلامة الأنماط والأنواع البرمجية (Typecheck)
npm run lint

# 4. بناء نسخة الإنتاج (Production Build)
npm run build
```

## 📦 خطوات تحويل المشروع إلى تطبيق أندرويد (Android APK / AAB)

بفضل بنية PWA القياسية وتوافق الشاشات المتجاوب، يمكن تحويل المشروع إلى تطبيق أندرويد أصلي (Native Android APK/AAB) بخطوات يسيرة عبر **Capacitor**:

```bash
# 1. تثبيت Capacitor
npm install @capacitor/core @capacitor/cli @capacitor/android

# 2. تهيئة المشروع
npx cap init "دليل سوريا" "sy.dalil.app" --web-dir dist

# 3. بناء واجهة الويب
npm run build

# 4. إضافة منصة أندرويد
npx cap add android

# 5. فتح المشروع في Android Studio لبناء APK أو AAB
npx cap open android
```
في Android Studio، اختر: **Build > Build Bundle(s) / APK(s) > Build APK(s)** لإنتاج ملف APK قابل للتثبيت فوراً.
