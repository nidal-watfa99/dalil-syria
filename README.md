# DALIL SYRIA | دليل سوريا — إصدار 2026

دليل شامل ومتكامل للمعاملات الحكومية السورية، والأسعار الرسمية والتقديرية، تغطية شاملة لكل الخدمات الاجتماعية 
والنقل والمواصلات، والمحافظات الـ 14، والخريطة الجغرافية التفاعلية، ونماذج الذكاء الاصطناعي المجانية الرسمية، والمساعد الذكي المدعوم بنموذج Google Gemini 2.5 Flash.

---

## 🌟 الميزات الرئيسية

1. **معاملاتي الشامل (الأولوية القصوى)**:
   - حصر رسمي وتفصيلي لكافة المعاملات في سوريا (حصر الإرث الشرعي والقانوني، جوازات السفر، السجل المدني، رخص القيادة، القيد العقاري، ساعات الكهرباء، السجل التجاري، معادلة الشهادات، وغيرها).
   - توضيح دقيق للشروط، خطوات التقديم، الوثائق المطلوبة (أصول ونسخ)، الرسوم المحدثة لعام 2026، والمدد المتوقعة، والمراجع القانونية ومراكز خدمة المواطن.
   - محرك بحث ذكي متطور يطابق الكلمات باللغة العربية مع معالجة وتطبيع الهمزات وتعدد الكلمات.

2. **الخريطة التفاعلية الشاملة لخدمات سوريا**:
   - تعمل تلقائياً على الفور بمجرد الدخول.
   - تدعم التبديل اللحظي بين 4 طبقات: شوارع واضحة (OpenStreetMap)، أقمار صناعية عالية الدقة (ArcGIS)، والنمط الداكن (CartoDB)، والتضاريس.
   - شريط تحكم كامل ومتقدم لتصفية المعالم (وزارات، مراكز خدمة مواطن، هجرة وجوازات، كراجات، مطارات، موانئ) واختيار أي محافظة وفحص الإحداثيات المباشرة.

3. **هوية بصرية فاخرة مستوحاة من Google AI Studio**:
   - تصميم داكن أنيق مبني على درجات `#131314` و `#1e1f20` و `#282a2c` و `#333537`.
   - خطوط عربية واضحة ورسمية (IBM Plex Sans Arabic و Cairo).
   - بطاقات ناعمة ذات حواف مدروسة وأزرار بلون Google Blue المميز `#1a73e8`.

4. **فهرس نماذج وأدوات الذكاء الاصطناعي المجانية الرسمية**:
   - روابط مباشرة وأصلية لأقوى النماذج العالمية (Google AI Studio, Google Gemini, DeepSeek V3/R1, ChatGPT, Claude, Microsoft Copilot, Perplexity, Groq, HuggingChat, Qwen, Mistral, DuckDuckGo AI).
   - توضيح الحصص المجانية وشروط الاستخدام ونصائح الوصول للمواطنين داخل سوريا.

5. **المساعد الذكي للخدمات**:
   - محادثة تفاعلية مباشرة مدعومة بنموذج `gemini-2.5-flash` للإجابة عن استفسارات المعاملات وتفاصيل الرسوم والإجراءات.

6. **تطبيق ويب تقدمي (PWA)**:
   - تثبيت سلس على سطح المكتب والأجهزة المحمولة مع أيقونات عالية الدقة وشاشات بداية.
   - دعم كامل للعمل في وضع عدم الاتصال (Offline Ready).
   - دعم القراءة الصوتية (Text-to-Speech) باللغة العربية مع التحكم بالسرعة.
   - دعم البحث الصوتي المباشر باللغة العربية (Voice Search).

## 📂 بنية المشروع المصدرية

- `server.ts`: خادم Express متكامل مع Vite Middleware ومسارات API الآمنة.
- `src/views/`: شاشات وواجهات التطبيق (المعاملات، الوزارات، المحافظات، الخريطة، الذكاء، الأسعار، النقل، السفر، الإعدادات).
- `src/data/`: قواعد البيانات الموثقة لعام 2026 (المعاملات، الوزارات، المحافظات، المواقع، الأسعار، المسارات، نماذج الذكاء).
- `src/hooks/`: خطافات React للبحث الصوتي، القراءة الصوتية، وتثبيت الـ PWA.
- `src/utils/`: دوال تطبيع وتدقيق البحث العربي والتعامل مع النصوص.
- `public/`: الأيقونات والشعارات وأصول PWA.
- `server/`: طبقة الذكاء الاصطناعي الموحّدة (المزودون، تخزين المفاتيح المشفّر، مسارات الإدارة).
- `scripts/package-source.cjs`: يبني ملف ZIP المصدري للتسليم **خارج التطبيق** في `release/`.

## 🤖 الذكاء الاصطناعي وإدارة المفاتيح

- المزودون: Google Gemini، OpenAI، Anthropic، DeepSeek، Groq (واجهة موحّدة في `server/providers.ts`؛ إضافة مزود = إضافة عنصر واحد).
- المفاتيح **على الخادم فقط**: إمّا متغيرات بيئة (`GEMINI_API_KEY` …) أو مخزَّنة مشفّرة AES-256-GCM في `data/ai-secrets.json` عبر صفحة «إعدادات الذكاء الاصطناعي».
- صفحة الإدارة محمية بـ `ADMIN_TOKEN`؛ بدونه تُعطَّل مسارات الإدارة (503). الحفظ من الواجهة يتطلب `AI_SECRETS_ENCRYPTION_KEY`.
- لا يُعاد أي مفتاح إلى المتصفح (يُعرض آخر 4 محارف فقط)، ولا يُحفظ في localStorage/sessionStorage.
- مسؤولية المفتاح والحصة والتكاليف على صاحبه وفق شروط المزود؛ الأسعار والحصص المجانية قد تتغير.

## 📦 ملف المصدر للتسليم

```bash
npm run package:source   # ينتج release/dalil-syria-2026-source.zip
```
الملف لا يحتوي `node_modules` ولا `data/` ولا أي ملف `.env` حقيقي، ويُفحص تلقائياً من المفاتيح قبل التغليف.

## 🖥️ تثبيت التطبيق (PWA)

يُثبَّت من المتصفحات الداعمة (Chrome/Edge على Windows وmacOS وLinux، وChrome على أندرويد، وSafari على iOS عبر «إضافة إلى الشاشة الرئيسية»). هذا PWA وليس برنامجاً مكتبياً أصلياً (EXE/MSI/DMG). العمل دون إنترنت محدود بالواجهة المخزّنة مؤقتاً؛ المساعد والخريطة والبحث عن حالة البوابات تتطلب اتصالاً.
